# Fotufilm engine update — 2026-10-15

Linux CUDA uses upstream `9242d189b6f8321a27c6f6a345aeb4e5991da569`, plus our additive float-memory input and CUDA build patch. Engine and matching resources ship together, with upstream notices and profile licenses. CPU/Vulkan and macOS keep the prior v1.11 fallback.

Relevant upstream changes include two-layer grain tiles and refitted Fuji sensitivity profiles. Existing recipe values remain compatible, but new grain/profile behavior can change pixels. A recipe retains its authored `engine`; a resolved render records the installed `render_engine`, which also invalidates film caches. External runtimes are labelled separately. For exact reproduction, keep the old container/runtime with the old workflow.

The upstream layered light-transport improvements are available in this engine, but this integration still requests legacy halation. This update does not silently change that rendering model, add upstream look-file importing, or add a true HDR display transport.

## Validation

RTX PRO 6000, same worker, 1280×720 synthetic linear HDR gradient, 24 measured frames after two warm-up frames per stock; float input and float output, no video encoder or network:

| Stock | Previous median / p95 | Updated median / p95 |
|---|---|---|
| Vision3 250D | 16.72 / 20.82 ms | 14.84 / 17.27 ms |
| Provia 100F | 16.69 / 19.36 ms | 14.66 / 22.38 ms |

Median film processing improved in this small sample; Provia's tail latency increased. These numbers are not end-to-end playback FPS or guarantees for arbitrary clips/resolutions. All native render, float-range, preview, cache, grading and export regression tests passed on the updated engine.

The NVIDIA source branch was separately exercised on CUDA 13 / torch 2.10 / NVIDIA VFX 0.2.0.0: two 640×360 frames produced finite linear output up to 3.20 after PQ decoding. Core Save Image (Advanced), EXR32 / linear, round-tripped negative and above-white test values exactly. Comfy's executor tests prove unselected source branches are not executed. The LTX inference settings are unchanged; only its optional-save decoder is wrapped to run on demand; this update did not rerun neural LTX generation.

## Upgrade

Run the pack's `install.py` during the remote image build, then restart ComfyUI. The installer verifies archive and library checksums and places new profiles in `linux-runtime/float-resources`, separate from legacy resources. Loading a stale CUDA binary reports an installation error rather than mixing engine versions. The lock and build patch live in `runtime/float-engine-lock.json` and `scripts/prepare_float_engine.py`.

NVIDIA HDR requires its separate node pack and CUDA-compatible NVIDIA dependencies. It is an optional upstream source processor; it does not replace LTX or Fotufilm. The player continues to show an SDR display conversion of the float source.
